# لوحة تحكم Sheep & Burger

لوحة إدارة المطعم (الطلبات، المنيو، العروض، الكوبونات، الإعدادات)، متصلة بقاعدة Supabase، وتعمل كتطبيق على الهاتف (PWA).

## هيكل المشروع

- `index.html`: الصفحة الرئيسية للوحة.
- `css/admin.css`: التصميم.
- `js/00` إلى `js/15`: المنطق بالترتيب (15 = تسجيل تطبيق الهاتف).
- `sw.js`: Service Worker لتخزين ملفات الواجهة. لا يخزّن أي طلب إلى Supabase.
- `manifest.webmanifest` و`icons/`: بيانات التطبيق والأيقونات.
- `.github/workflows/pages.yml`: نشر تلقائي على GitHub Pages عند الرفع على `main`.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع محتويات هذا المجلد في جذره (`index.html` يكون في الجذر).
2. من Settings ← Pages ← Build and deployment، اختر Source: **GitHub Actions**.
3. أي push على فرع `main` ينشر النسخة الجديدة تلقائيًا. الرابط يكون بالشكل `https://<username>.github.io/<repo>/`.

## تثبيت اللوحة كتطبيق على الهاتف

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← "تثبيت التطبيق" أو "Add to Home screen".
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ⬆️ ← "إضافة إلى الشاشة الرئيسية".

## ملاحظات أمان مهمة

- مفتاح Supabase المستخدم في الواجهة هو المفتاح العام (publishable). الحماية الحقيقية تعتمد على سياسات RLS وصلاحيات الأدوار في قاعدة البيانات، وعلى Edge Functions.
- بما أن اللوحة على رابط عام، فعّل المصادقة الثنائية (MFA) لحسابات المالك والمدير.
- إذا كان المستودع عامًا، الكود مرئي للجميع. مستودع خاص يحتاج خطة GitHub مدفوعة لتفعيل Pages عليه.
- لا تضع أي مفتاح `service_role` في هذه الملفات أبدًا.
- ملاحظة: `'unsafe-inline'` لسه موجودة في CSP بسبب أحداث `onclick` المدمجة في الـ HTML.
